# Example model parameters

Example model parameters for `COA_standard()`

## Usage

``` r
model_param_ex
```

## Format

A data frame with four variables and one row: `nind` which is the number
of individuals, `nrec` is the number of receivers in the array, `tsteps`
is the number of time steps used in the example, and `ntrans` is the
number of expected transmissions within a time step.

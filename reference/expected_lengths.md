# Expected lengths of variables in `standata`

Expected lengths of variables in `standata`

## Usage

``` r
expected_lengths(recX = NULL, recY = NULL, ntest_len = NULL)
```

## Arguments

- recX:

  is the receiver or station x coordinates (e.g, lon).

- recY:

  is the receiver or station y coordinates (e.g., lat).

- ntest_len:

  is the number of reference tags which is used as length by `testX` and
  `testY`.
